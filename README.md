# GaitLogic Planner

GaitLogic Planner 是一个面向严肃跑者的训练计划与训练日志 Web 系统。

它希望解决的问题不是简单“记录今天跑了几公里”，而是帮助跑者把 **训练周期、每日计划、训练日志、配速规则、Excel 导入、AI 课表草稿和训练复盘** 放到一个统一系统里管理。

> AI 生成内容仅作为训练计划参考，不构成医疗建议、康复建议或专业教练处方。实际训练前请结合自身状态、伤病情况和专业建议进行调整。

***

## 项目定位

很多跑者会同时使用 Excel、手表 App、聊天记录和笔记软件来管理训练，但这些数据往往是分散的：

- 训练计划写在 Excel 里；
- 每天执行记录在手表 App 里；
- 训练复盘写在聊天记录或备忘录里；
- 配速区间靠经验记忆；
- 备赛周期缺少统一的结构化管理。

GaitLogic Planner 的目标是提供一个更清晰的训练管理闭环：

```text
制定计划 → 执行训练 → 填写日志 → 查看统计 → 复盘调整 → 继续训练
```

它更适合这些用户：

- 有固定训练计划的跑者；
- 正在备赛 5km、10km、半马或全马的跑者；
- 习惯用 Excel 写训练计划，但希望逐步迁移到 Web 系统的跑者；
- 希望结合 VDOT / 丹尼尔斯配速体系管理训练强度的跑者；
- 想尝试 AI 生成课表草稿，但仍希望保留人工确认流程的跑者。

## 功能概览

| 模块        | 说明                         |
| --------- | -------------------------- |
| 用户系统      | 注册、登录、JWT 认证、多用户数据隔离       |
| Dashboard | 查看跑量、训练次数、完成情况和训练分布        |
| 训练周期      | 管理一个完整备赛阶段，例如夏训、校运会周期、半马周期 |
| 训练块       | 在周期下划分基础期、强化期、专项期、减量期等阶段   |
| 训练计划      | 维护每天的训练安排，包括距离、类型、配速和训练内容  |
| 今日训练      | 快速查看当天计划和训练目标              |
| 训练日志      | 记录实际完成距离、用时、配速、心率、体感和复盘    |
| Excel 导入  | 下载标准模板，批量导入训练周期、训练计划和日志    |
| VDOT 计算器  | 根据比赛成绩估算训练配速区间             |
| 配速规则      | 保存 REC、E、M、T、I、R 等训练配速规则   |
| AI 课表     | 基于用户输入生成结构化训练计划草稿          |
| 内测反馈      | 提交使用反馈和功能建议                |

## 系统架构

GaitLogic Planner 采用前后端分离架构：

- 前端使用 Vue 3、TypeScript、Vite、Element Plus、ECharts；
- 后端使用 FastAPI、SQLAlchemy 2.x、MySQL；
- Excel 导入导出基于 openpyxl；
- AI 课表草稿通过 OpenAI-compatible SDK 调用 DeepSeek API；
- 生产环境建议使用 Nginx 反向代理前端静态资源和后端 API。

## 使用流程

新用户可以按照下面的顺序使用系统：

```text
注册账号
  ↓
登录系统
  ↓
创建训练周期
  ↓
创建训练块
  ↓
添加每日训练计划
  ↓
每日查看今日训练
  ↓
训练完成后填写训练日志
  ↓
在 Dashboard 查看统计与完成情况
  ↓

  ↓

```

## 注册与登录

用户首次使用时需要注册账号。系统会为每个用户创建独立的数据空间，不同用户之间的训练周期、训练计划、训练日志、配速规则和 AI 草稿互相隔离。

![登录注册](docs/images/login.png)

登录成功后，前端会保存认证状态，并在后续请求中自动携带 Token。后端根据当前登录用户绑定数据，前端不需要手动传递 `user_id`。

## Dashboard

Dashboard 用于查看训练数据概览，帮助用户快速了解近期训练状态。

![Dashboard](docs/images/dashboard.png)

Dashboard 主要关注这些问题：

- 最近跑了多少？
- 计划完成率怎么样？
- 有氧、节奏、间歇、长距离比例是否合理？
- 当前训练周期的跑量趋势如何？
- 是否存在训练堆积或长期缺课？

适合在每周复盘时打开 Dashboard，结合实际体感判断后续训练是否需要调整。

***

## 训练周期

训练周期是系统中最高层级的训练结构，适合管理一个完整备赛阶段。

例如：

- 2026 夏训周期；
- 2026 校运会备赛周期；
- 2026 眉山东坡半马周期；
- 2027 春季马拉松周期。

一个训练周期通常包含：

- 周期名称；
- 开始日期；
- 结束日期；
- 目标赛事；
- 目标成绩；
- 周期说明。

训练周期适合回答的问题是：

```text
我现在处在哪个备赛阶段？
这个阶段最终服务于什么目标？
训练安排应该围绕什么能力展开？
```

***

## 训练块

训练块是训练周期下的阶段划分。

一个周期可以拆成多个训练块，例如：

```text
2026 夏训周期
├── 基础有氧块
├── 阈值提升块
├── 专项强化块
└── 减量调整块
```

每个训练块可以对应不同训练重点：

| 训练块   | 主要目标        |
| ----- | ----------- |
| 基础有氧块 | 稳定跑量，提升有氧容量 |
| 阈值提升块 | 提高持续输出能力    |
| 专项强化块 | 接近目标赛事强度    |
| 减量调整块 | 降低疲劳，保持状态   |

## 训练计划

训练计划用于管理每天应该完成的训练内容。

![训练计划列表](docs/images/workout-list.png)

一条训练计划通常包括：

- 日期；
- 所属训练周期；
- 所属训练块；
- 训练类型；
- 计划距离；
- 计划时长；
- 目标配速；
- 目标心率；
- 训练内容；
- 训练目标；
- 备注。

示例：

```text
日期：2026-07-02
类型：T 节奏跑
内容：热身 3km + 3×3km @3:35-3:40/km，间歇慢跑 3min + 放松 2km
目标：提升半马阈值能力
```

***

## 今日训练

今日训练页面用于快速查看当天训练安排。

![今日训练](docs/images/today-workout.png)

它适合用户每天训练前查看：

- 今天是否有训练；
- 今天是什么训练类型；
- 计划距离是多少；
- 目标配速是多少；
- 训练内容如何执行；
- 是否已经填写训练日志。

如果当天没有训练计划，系统会提示暂无训练安排。

## 训练日志

训练完成后，用户可以填写训练日志，用于记录实际完成情况并和原计划对比。

![训练日志填写](docs/images/workout-log-edit.png)

训练日志通常包括：

- 实际距离；
- 实际用时；
- 平均配速；
- 平均心率；
- 最大心率；
- 主观体感；
- 疲劳程度；
- 完成状态；
- 实际训练内容；
- 训练复盘；
- 备注。

建议训练日志不仅记录数据，也记录体感和调整依据。例如：

```text
实际完成：14km @4:48/km，平均心率 143。
体感整体轻松，前半程腿有些沉，8km 后逐渐跑开。
今天控制得比较好，没有跑快。明天可以正常进行节奏课。
```

## Excel 标准模板导入

系统支持通过标准 Excel 模板批量导入训练数据。

![Excel 导入](docs/images/excel-import.png)

适合这些场景：

- 已经在 Excel 中写好了完整训练计划；
- 想一次性导入多个训练周期；
- 想批量导入训练块、每日计划和训练日志；
- 想从线下表格迁移到系统中管理。

使用流程：

```text
进入 Excel 导入页面
  ↓
下载系统提供的标准模板
  ↓
按模板填写训练数据
  ↓
上传 .xlsx 文件
  ↓
系统校验并导入
  ↓
查看成功数量、失败数量和错误明细
```

注意：系统只支持后端生成的标准 Excel 模板，不兼容任意非标准 Excel。请不要随意修改模板中的 Sheet 名称、表头字段和字段顺序。

上传数据会自动绑定当前登录用户，前端不会传递 `user_id`。

## VDOT / 丹尼尔斯配速计算器

系统内置 VDOT / 丹尼尔斯配速计算器，用于根据比赛成绩估算训练配速区间。

![VDOT 配速计算器](docs/images/pace-calculator.png)

用户输入比赛距离和比赛成绩后，系统会估算：

- 近似 VDOT；
- REC 恢复跑配速；
- E 有氧跑配速；
- M 马拉松配速；
- T1 / T2 阈值配速；
- I 间歇配速；
- R 重复跑配速。

VDOT 结果只代表基于比赛成绩的训练配速估算。实际执行时仍需要结合天气、疲劳、海拔、睡眠、伤病和当前训练周期目标进行调整。

***

## 配速规则与配速档案

配速规则用于保存当前账号的训练配速体系。

![配速规则](docs/images/pace-rules.png)

示例：

| 类型  | 含义    | 示例           |
| --- | ----- | ------------ |
| REC | 恢复跑   | 5:10-5:50/km |
| E   | 有氧跑   | 4:35-5:05/km |
| M   | 马拉松配速 | 3:55-4:05/km |
| T1  | 低阈值   | 3:38-3:45/km |
| T2  | 高阈值   | 3:30-3:36/km |
| I   | 间歇    | 3:12-3:20/km |
| R   | 重复跑   | 68-75s/400m  |

用户可以将某一次 VDOT 计算结果保存为配速档案，并一键应用到当前账号的配速规则中。

## AI 课表草稿生成器

AI 课表草稿生成器用于根据用户输入的跑者信息生成结构化训练计划草稿，
用户首先可以在“AI 教练偏好”中设置自己的训练偏好，这样生成的课表会更加符合用户的需求，适合追求个性化定制课表的用户。

![AI 教练偏好](docs/images/ai-preference.png)

用户通常需要填写：

- 当前跑量；
- 近期 PB；
- 目标赛事；
- 目标成绩；
- 每周可训练天数；
- 计划周数；
- 当前训练水平；
- 强度风格；
- 训练偏好；
- 伤病或限制说明。![AI 课表草稿](docs/images/ai-plan.png)

AI 会生成训练计划草稿，但不会直接覆盖正式训练计划。系统采用两步流程：

```text
生成 AI 草稿
  ↓
用户检查与确认
  ↓
点击“应用为正式计划”
  ↓
写入训练周期、训练块、每日训练计划和默认训练日志
```

因为项目现在还在开发中，所以只接入了deepseek v4 flash和pro模型，后续开放会增加模型设置，这样用户可以根据自己的需要调用对应的模型。

默认规则：

- 每个用户每天最多生成 3 次；
- 同一用户两次生成至少间隔 60 秒；
- 24 小时内相同输入优先命中缓存；
- 草稿、调用记录和额度按当前登录用户隔离。

AI 课表适合辅助构思训练结构，但最终安排仍应由用户结合实际状态判断。

## 内测反馈

系统提供内测反馈功能，方便用户提交问题和建议。

可以反馈的内容包括：

- 页面 Bug；
- 数据异常；
- Excel 导入问题；
- AI 生成结果问题；
- 功能建议；
- 交互体验问题；

```bash

npm run dev
```
