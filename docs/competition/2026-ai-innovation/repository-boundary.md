# Repository boundary

| Location | Allowed content |
| --- | --- |
| Public product repository | Product source, reusable models/frameworks, generic rules, anonymous test fixtures, generic survey/evaluation code, public documentation |
| Private competition repository | Submission documents, competition configuration, anonymized study outputs, evaluation reports, presentation and defense material, video scripts/assets |
| Neither Git repository | API keys, `.env` values, Garmin tokens, passwords, SSH private keys, production backups, raw uploads, or unredacted personal data |

Raw survey answers, interviews, experimental raw results, competition accounts, private rule parameters, private prompts, videos, defense strategy, and unpublished results are private competition materials. A participant is referenced by a pseudonymous `participant_id`, never a name, email, or phone number.
