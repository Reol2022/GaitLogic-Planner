# 日常 UI：适度简洁版

> 历史方案：当前界面采用移动端适配版本的布局，本文描述的简化方案未保留。

2026-11-06，该方案在简化布局的基础上恢复常用操作、关键训练摘要和首屏统计展示。

## 恢复可见信息

- 今日：课表/记录入口、同步或导入、问教练直接可用；增加恢复与准备度摘要，展示现有评估的数据质量、打卡情况和负荷变化。缺数据时明确提示，不把null转换为0，不从摘要推断恢复充分。
- 计划：周期目标、已有赛事目标字段、本周安排；查看计划、日历、讨论调整三个入口直接可用。讨论仍只进入Coach，不自动修改计划。
- 记录：默认可见一张计划/实际跑量图和三个现有周期指标；最近活动由3条增加到5条。数据仍区分周期计划统计与设备记录，不改变统计口径。
- 完整类型分布、完成状态、反馈雷达和细节保留在“更多统计”中；关闭细节只销毁三张辅助图，保留首屏跑量图。重新展开可重建辅助图。
- “我的”恢复卡片、图标底色与简短说明；恢复轻阴影和页面层次，但不恢复重复流程导航、大片色块和冗余工具按钮。
- 同步任务恢复新增/更新/待确认摘要，其余原始信息仍可展开。

## 边界

新增可见数据全部来自既有接口，不增加Garmin/模型请求。重要风险提醒继续在折叠区域外，审批与用户隔离不变。恢复摘要使用中性色，不把颜色当成健康结论。没有周期、缺少数据或非今日日期，均不编造目标或恢复值。

替换原quiet-experience.css为balanced-experience.css，避免叠加两套相反的样式。上一轮quiet-ui文档保留为历史记录，其默认3条/全部图表收起的描述不再代表当前界面。

## 验证

前端157项测试通过；Typecheck、统一生产构建通过（仍有既有大bundle警告）。合成浏览器验证320/390px手机、740px横屏及1440px桌面：常用入口、可见风险/恢复摘要、首屏跑量图、更多图表重开、周期目标和讨论入口。

验证只使用合成数据，不是生产或真实模型验收；不修改数据库、不部署、不自动提交/推送。开发入口继续为web目录 `npm run dev`。
