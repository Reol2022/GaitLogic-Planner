# 分组侧栏

参考 Garmin Connect 的层级导航，保留 GaitLogic 品牌及现有功能，不添加社交或营养模块。

## 交互

- 快捷入口：今日、日历、待办、AI 教练。
- 分组：训练记录、状态与恢复、训练与计划、设备与数据、个人与设置；管理员另见管理后台。
- 多组可同时展开。深层页面及兼容路由自动定位对应子项。
- 品牌区固定，菜单独立滚动；桌面可收起为图标，并通过悬浮菜单继续访问子项。
- 深色背景、青蓝图标、灰色正文，选中子项使用白色左标记。
- 手机底部为最多4个自选入口及固定“更多”，通过抽屉访问完整分组，不将桌面侧栏挤进手机界面。

## 代码与边界

### 用户自定义

从侧栏底部“自定义菜单”或顶部设置菜单进入：

- 选择最多6个常用入口并上下排序，已固定入口不在组内重复显示。
- 隐藏分组/单个功能，调整分组顺序及组内顺序。
- 保存立即生效，取消不改变现有配置；恢复默认需点击保存确认。
- 允许隐藏全部菜单，但配置入口始终保留。
- 手机“更多”中的常用入口、分组显示/隐藏与顺序沿用桌面设置；手机底部入口单独选择和排序，最多4个，固定“更多”不能移除。
- 抽屉始终保留“我的主页”及“自定义菜单”；选中页面后关闭抽屉，抽屉内容独立滚动。
- 旧版保存数据缺少 `mobileShortcuts` 时自动补充默认的今日/计划/记录/教练，不覆盖桌面个性设置。

`sidebarPreferences.ts` 校验版本、去重、限制数量，只接受既有菜单目录中的ID/路径，再投影到当前账号可访问的菜单。不能注入任意URL或绕过管理员/设备权限。新菜单默认可见，未知或损坏配置安全回退。

配置存储于当前站点浏览器的 `gaitlogic:sidebar:<认证用户ID>:v1`，不包含训练或认证信息。不同账号使用独立键；退出后恢复默认，其他标签页修改会同步。浏览器禁止存储时仍在本次页面生效，但明确提示无法持久保存。清理浏览器数据会丢失配置，尚不支持跨设备同步。本轮无需数据库迁移。

`sidebarNavigation.ts` 管理菜单及路由映射，`SidebarNavigation.vue` 管理展开与展示；AppLayout 保持现有用户和功能开关来源。菜单隐藏不是后端授权的替代，原有 API 权限不变。

不涉及数据库、训练规则、模型或线上配置。本轮未提交、推送或部署。
