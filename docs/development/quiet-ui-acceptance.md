## 减少默认展示

- 删除今日、计划、复盘、Garmin页重复的四步流程导航。
- 顶部移除重复标语和上传/待办/同步/退出按钮；低频入口归入设置菜单。管理员侧栏只保留控制台，旧系统/规则/AI设置仍可从管理员菜单访问。
- 今日以课表内容及“记录训练”为主，不展示无意义的空状态标签；同步、导入和教练分析展开使用；设备同步按钮不再重复出现。重要规则和恢复警告留在折叠区外。
- 计划默认展示当前周期与本周安排，额外操作合并到一个工具区域。
- 记录默认展示最近3条已加载设备活动，可展开本页其余记录，不再次请求、不伪称覆盖整个时间段。数据来源与关联解释展开阅读。
- 周期统计与图表默认收起，展开时创建图表、关闭时销毁，再打开能重新绘制；保留用户的展开状态与原有统计口径。
- Garmin范围由五个并排选项改为单个选择框；数量、时间及偏好展开，失败原因和可取消/重试操作保持直接可见。
- “我的”从多张大卡片改为单一分隔列表，完整高级入口仍在更多工具内。首次引导保留3条开始路径，去除默认推荐式高亮和重复说明。
- 统一降低阴影、色块与文字层级，保留44px触控区、键盘可达性及手机安全区。管理后台参数控件本轮未删减。
