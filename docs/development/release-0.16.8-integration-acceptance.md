## 入口卡片修复

根因：入口提示直接由 URL 的 `topic/date` 推导；创建新会话后未消费这些参数，提示继续显示，刷新也再次出现。

成功创建新会话后立即隐藏提示，并通过 router.replace 只移除入口参数，保留其他查询参数与 hash。创建失败、取消覆盖未发送内容时不消费入口。只填入输入框，不自动发送、不请求模型、不修改计划。

自动化覆盖成功消费、失败重试、保留其他参数；浏览器覆盖桌面、390px、320px、刷新恢复与减少动画偏好。
