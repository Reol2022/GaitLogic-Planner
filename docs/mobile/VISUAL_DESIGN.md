## 设计依据

移动端默认石墨黑背景 `#111419`、炭灰卡片 `#1B232D`，蓝色突出导航和计划，绿色承载活动标记。浅色外观从「我的 → 应用设置」切换，偏好仅保存在本机。网页端样式独立维护。

uni-app x 使用原生 view/text/image 等组件实现同一套设计语言，不直接移植 Element Plus 或浏览器 DOM。颜色不代表医疗风险等级。

## 信息架构

今日先看活动，再看训练安排和恢复。训练分为进度、活动与日历；日历可点箭头或横滑，点日期查看当天记录。洛教练保留固定输入栏，空对话提供只填入、不自动发送的起始问题。工具按用途分组，个人页区分账号、设备和设置。

底部固定五个入口：今日、训练、Gilo、工具、我的。训练工具箱为一级入口，采用带图标的分组列表；训练统计可从训练页和工具箱进入。

训练计划与实际事实仍分开；缺失值不补零；生成、预览、正式应用仍分开确认。
