2026-11-26；基线 `96f32d4`，沿用 `feat/mobile-v0.1.0-foundation`。本轮保留现有 Web、后端与所有无关工作树修改，不切换生产入口。

## 架构与优先级

复用现有 REST、JWT、用户归属、规则引擎、AI 草稿与 HITL。原生页面共享 ApiClient、按账号代际隔离的 PageScope、有界表单字段白名单和统一视觉样式；不复制后台业务，不把模型或设备密钥下发到客户端。

训练工具箱作为底部「工具」一级入口；周期 → 训练块 → 每日计划逐级选择，避免手填父级 ID。固定五个主导航继续承载今日、训练、Gilo、工具、我的；训练统计通过训练页与工具箱进入。

## 安全与一致性

- 不信任前端 user_id，客户端字段白名单不包含归属、锁或来源证明字段；所有请求仍由后端认证与业务授权。
- 日志与恢复只发送改变的字段，不把空值补零，不把活动 RPE 当作整堂训练 RPE；整堂训练自评必须由用户明确填写。
- AI 自动建议不静默覆盖表单；输入改变使已有检查失效。生成、草稿应用、周期启用与 Proposal 审批分开确认。
- 超时或取消等待不代表后端任务终止。写请求不自动重试；提示先读取状态，防止重复生成或应用。
- 新页面隐藏时取消所属网络等待，清理个人数据；PageScope 和 ApiClient 同时拒绝旧账号的迟到响应。
- 开发与测试不触发真实 Garmin、付费模型、生产数据写入或部署。
