# 路线与发布门槛

微信与 Android Vapor 开发模式编译已通过；接下来完成设备运行、授权账号登录、真实训练、图表、Gilo 和跨用户验证后，再评估小范围内测。不能用传统 uni-app、WebView 或假流式绕过。

后续优先：日常反馈与同步体验闭环；原生可靠性（安全存储、内存/列表、取消恢复、设备矩阵）。Pinia/uni-ui x 等按真实需要验证后引入；没有服务端文本流前不增加空的流式 API。

不提前做支付、GPS、蓝牙、推送、HealthKit/Health Connect、新 Provider、移动后台、完整计划编辑或上架。

## 微信绑定

后端验证微信 code，并在用户证明既有 GaitLogic 身份后绑定同一 User；不能按昵称或客户端 user_id 合并，不能创建丢失原数据的独立账号。解绑、冲突、换绑和多端退出仍需设计，当前未实现。
