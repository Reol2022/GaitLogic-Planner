# 需求说明

## 项目定位

Gaitlogic Planner 是一个面向严肃跑者的训练计划与训练日志 Web 系统。当前 MVP 只做训练计划制定、Excel 导入记录、训练日志、周/月统计基础数据和配速规则管理。

## 核心数据来源

数据库设计以最新版 Excel《严飞_夏训计划与训练日志_下拉样式版.xlsx》的四个核心 Sheet 为准：

- `计划索引`：每日训练计划的主来源
- `训练日志`：实际完成记录和训练复盘的主来源
- `每周复盘`：训练块复盘的主来源
- `配速与规则`：配速规则的主来源

`总览Dashboard` 和 `6月/7月/8月计划页` 暂时视为展示页，不作为数据库主来源。

## 当前范围

- 训练周期 `TrainingCycle`
- 训练块 `TrainingBlock`
- 计划训练课 `PlannedWorkout`
- 训练日志 `WorkoutLog`
- 训练块复盘 `BlockReview`
- 配速规则 `PaceRule`
- Excel 导入任务 `ExcelImportJob`

## 明确不做

- 不做 Excel 解析
- 不做前端业务
- 不做 FastAPI 业务接口
- 不做 Garmin 同步
- 不做 AI 教练
- 不做 App 和小程序
- 不做多用户 SaaS
- 不做社交功能
