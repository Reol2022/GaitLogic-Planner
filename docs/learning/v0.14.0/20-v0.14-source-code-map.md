# v0.14 源码地图

- `server/observability/tracing.py`：内部 Span、白名单、父子关系与 fan-out。
- `server/observability/sinks.py`：可选 OpenTelemetry Trace Adapter。
- `server/observability/metrics.py`：Metrics Recorder、Sink、有界 P50/P95 聚合。
- `server/observability/factory.py`：配置到 Trace/Metrics side channel 的装配。
- `server/provider_reliability.py`：统一 Provider Failure Taxonomy 与退避策略。
- `server/agent/orchestrator.py`、`server/agent/registry.py`、`server/agent/tools/knowledge_tools.py`：Provider、Tool、RAG、Validator Span。
- `server/weekly_review_graph/workflow.py`、`server/adaptive_workflow/graph.py`、`server/services/adaptive_plan_approval_service.py`：Weekly、HITL、事务与版本链路。
- `server/agent/evaluation_regression/` 与 `scripts/evaluate_agent.py`：离线回归评测。
