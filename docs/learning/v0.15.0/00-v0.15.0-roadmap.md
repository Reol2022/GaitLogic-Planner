# v0.15.0 路线图

v0.15.0 的目标是让外部 MCP Host 能以受控方式读取 GaitLogic 的训练事实，而不是把数据库或 Agent 内部实现直接交给客户端。

## A：MCP Server Foundation（本阶段）

- 提供本地 `stdio` MCP Server；
- 只开放 `get_today_plan`、`get_recent_training`、`get_runner_state`；
- 复用 Coach Agent 的请求级只读 Tool Registry 与既有 Service；
- 设计内部 `McpExecutionContext`，但不实现认证或远程身份传递；
- 接入现有 Trace 与 Metrics 抽象。

## 后续边界

v0.15-B 才讨论可信 Host 身份注入与远程 Streamable HTTP。Resources、Prompts、写工具、计划 Proposal、审批、Multi-Agent 均不属于 A。任何后续写能力必须继续经过既有 Tool Policy、规则引擎、Validator、HITL 与版本事务，不能借 MCP 绕过它们。
