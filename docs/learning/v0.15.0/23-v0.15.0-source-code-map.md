# v0.15.0 Source Code Map

- `server/mcp/server.py`: SDK server, stdio entry and Tool registration.
- `server/mcp/http.py`: Streamable HTTP mounting, authentication and origin boundary.
- `server/mcp/adapters.py`: identity-scoped Tool-to-Service adaptation.
- `server/mcp/knowledge.py`: safe Resources and Prompts.
- `server/mcp/evaluation.py`: public MCP suite integrated with unified regression.
- `server/agent/evaluation_regression/`: shared runner, baseline and gates.
- `tests/test_mcp_*.py`: fictional protocol, security and read-only verification.
