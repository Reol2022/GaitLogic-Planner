# v0.16.0：可插拔向量检索路线

v0.16.0-A 在既有 Training Knowledge Corpus、Embedding Provider、Exact Cosine 索引和 Coach Knowledge Tool 之上，引入可插拔 Vector Store。目标不是改变训练知识、检索案例或 Agent 决策，而是让同一份版本化 Dense Embedding 可以由不同后端检索。

本阶段的两种实现是：

- `exact`：默认实现，使用仓库运行目录中的精确余弦相似度 JSON 索引；
- `qdrant`：可选的 Qdrant Dense Cosine 实现，支持本地嵌入式运行或由 `QDRANT_URL` 指向的远程服务。

两者共享同一 Corpus、Embedding Provider、Chunk ID、Metadata Filter 和 Index Manifest 规则。`KNOWLEDGE_VECTOR_STORE=exact` 仍是默认值，升级不会自动切换现有部署。

本阶段明确不包含 Hybrid Retrieval、BM25、Reranker、Query Rewrite、向量数据库管理后台或任何训练计划写入能力。后续阶段如要引入这些能力，必须先定义单独评测和安全边界，不能把它们混进 Dense Store 替换。
