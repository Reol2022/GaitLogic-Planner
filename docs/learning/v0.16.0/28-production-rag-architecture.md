# Production RAG Architecture

Raw curated sources become a versioned Corpus of chunk metadata. Dense and BM25 indexes are derived artifacts. A configured strategy retrieves bounded public top-k results, the server materializes Canonical References, and the read-only RAG tool supplies the Coach Agent. Trace, low-cardinality metrics, index freshness validation and safe fallback run across the chain. Retrieval explains training theory; it cannot alter deterministic TODAY facts or plans.
