# v0.16.0 Interview Guide

**Why is Legacy not blind?** It informed prior engineering decisions; only an independently authored frozen set can support a generalization decision.

**Dense, BM25, Hybrid and Rerank?** Dense captures semantic similarity; BM25 preserves exact terms; Hybrid unions bounded candidates with RRF; Rerank uses an external model to reorder a fixed candidate set.

**Why not choose by Recall alone?** A useful production choice also needs safe filters, ranking quality, latency, provider reliability, fallback and operational simplicity.

**What happens when the reranker fails?** The request retains the existing Hybrid RRF order and reports a safe limitation; it never invents sources or changes training decisions.
