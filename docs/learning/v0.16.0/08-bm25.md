# BM25：可复现的词法检索基线

BM25 按查询词在文档中的出现次数、该词在整个语料中的稀有程度，以及文档长度进行打分。GaitLogic 的实现位于 `server/knowledge_retrieval/sparse/bm25.py`，使用固定 `k1=1.2`、`b=0.75`，并按 `chunk_id` 处理同分排序，因此同一 corpus、同一 query 和过滤条件的结果可重复。

它不需要生成 Embedding，也不会在请求时访问网络。BM25 只负责候选知识 chunk 的排序；Canonical Reference、TODAY 的确定性事实、规则引擎和 Validator 均不变。

TF 是术语在当前 chunk 的频率；IDF 使在少数文档出现的术语拥有更大辨识度；长度归一化避免长 chunk 仅因字更多而占优。BM25 分数本身无上界，公开 API 为兼容既有 schema 只返回保序的 0 到 1 投影，不将原始分数作为业务结论。
