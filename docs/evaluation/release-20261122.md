## 回滚与剩余限制

保留上一版本和迁移前私有备份；代码回滚需同时复核安全开关与运行配置，重载 API 并检查 Worker、鉴权和健康。新增安全表为加法变更，不为回滚自动删表；数据库恢复必须经过单独授权及影响核验。

本批不解决所有审计风险：Web logout 全端撤销、完整 Token/费用原子结算、50 VU 混合容量复测、个人恢复基线等仍待后续专项。负荷 LOW 不代表医学恢复充分；UNKNOWN 比赛标签不会按距离或用户聊天自动升级为已验证事实。

受保护的无关迁移脚本及用户架构图片未纳入提交。本报告为部署后的文档补记，不改变上述生产代码提交。
