# GaitLogic v0.12.0 Alpha 使用说明

## 范围

本轮仅邀请 5～10 名熟人跑者验证训练知识引用、Coach 解释和故障降级。它不是医疗工具，也不会自动修改正式训练计划。

## 开始使用

1. 使用测试账号登录，不共享账号和密码。
2. 可创建完全虚构的计划；若使用个人训练数据，应先理解隐私说明。
3. 按正常流程记录计划和训练日志，等待 Runner State 形成可用状态。
4. 进入 `/coach`，依次尝试：
   - TODAY：询问今天应该怎样训练；
   - EXPLAIN：要求解释当前 Runner State 和数据限制；
   - GENERAL：询问不依赖个人数据的一般训练知识。
5. 展开“训练知识来源”，核对标题、章节、版本、证据等级和摘录是否有帮助。

## 正常现象

- Provider 不可用时会显示确定性降级结果；
- 没有匹配知识时引用列表为空，并说明知识覆盖有限；
- 数据不足时显示 UNKNOWN，不代表系统故障；
- TODAY 的规则结论始终优先于模型解释。

## 反馈

使用测试编号而非姓名提交反馈。请记录场景、设备类型、结果是否相关、引用是否有帮助和错误码；不要粘贴 Token、邮箱、手机号、精确轨迹或健康诊断资料。
