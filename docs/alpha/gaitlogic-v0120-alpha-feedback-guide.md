# GaitLogic v0.12.0 Alpha 反馈指南

## 最小反馈字段

- 测试编号；
- 跑者水平区间（初级 / 有规律训练 / 进阶）；
- 场景（TODAY / EXPLAIN / GENERAL）；
- 回答是否相关；
- 解释是否清晰；
- 引用是否有帮助；
- 是否愿意采纳；
- 风险提示是否合理；
- 问题分类；
- 自由反馈；
- 是否授权将脱敏结论用于产品改进。

## 不应收集

无需姓名、手机号、邮箱、精确住址、身份证件、完整 GPS 轨迹、疾病诊断、API Key 或设备 Token。伤病和医疗问题只记录“建议咨询专业人员”是否正确显示，不收集诊断材料。

## 问题分类

- `FACT_MISMATCH`：训练事实不一致；
- `DECISION_MISMATCH`：模型弱化或覆盖确定性规则；
- `REFERENCE_ISSUE`：来源缺失、无关或难理解；
- `DEGRADED_ISSUE`：故障时没有安全降级；
- `UI_ISSUE`：移动端、可访问性或布局问题；
- `PRIVACY_ISSUE`：出现不必要身份或敏感信息。
