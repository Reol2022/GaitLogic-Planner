# 开发路线

## 当前阶段：数据库 MVP

- 建立 MySQL 数据库结构
- 建立 SQLAlchemy 2.x ORM 模型
- 支持训练计划、训练块、计划训练课、训练日志、块复盘、配速规则和 Excel 导入任务记录
- 提供初始化数据库脚本
- 提供示例数据脚本
- 提供模型和约束测试

## 下一阶段：Excel 导入

- 读取最新版 Excel 的核心 Sheet
- 将 `计划索引` 映射到 `planned_workouts`
- 将 `训练日志` 映射到 `workout_logs`
- 将 `每周复盘` 映射到 `block_reviews`
- 将 `配速与规则` 映射到 `pace_rules`
- 用 `excel_import_jobs` 记录导入过程

## 后续阶段

- 网页制定训练计划
- 网页填写训练日志
- 周/月统计与复盘
- 设备同步扩展预留

- AI 教练
