# GaitLogic v0.12.0 Release Notes

## 版本目标

v0.12.0 将版本化训练知识接入只读 Coach Agent，并通过服务端 Canonical Knowledge Reference 提供可信来源。结构化训练事实和确定性规则继续负责个人状态与 TODAY 决策，RAG 只补充通用训练知识和解释依据。

## 用户可见变化

- Coach 页面新增“训练知识依据”，展示标题、来源、知识版本、证据等级、章节、限制和安全摘录。
- GENERAL、EXPLAIN 和 TODAY 可以在知识检索成功时返回可信引用。
- Provider、Embedding 或 Index 不可用时显示明确限制，不伪造来源；TODAY 的确定性建议仍可使用。
- 旧版 Coach 响应缺少 `knowledge_references` 时，前端继续兼容。

## 技术架构变化

```text
Versioned Corpus
→ OpenAI-compatible Embedding
→ Exact Cosine Index
→ Structured Retriever
→ read-only Agent Tool
→ request-scoped Reference ID
→ server Canonical Reference
→ Vue presentation
```

新增公开 Evaluation、Readiness CLI、真实 Provider Smoke 和 Alpha 运维文档。本版本没有新增数据库模型或迁移。

## 从 v0.11.0 升级

1. 备份当前代码、前端发布目录和服务端安全配置。
2. 部署 v0.12.0 代码并安装 Python/Node 依赖。
3. 保持 `COACH_AGENT_KNOWLEDGE_RETRIEVAL_ENABLED=false`。
4. 执行 `python scripts/knowledge_corpus.py validate`。
5. 使用真实 Embedding Provider 构建索引，记录生成的 Index ID；不得将 `deterministic_test` 索引用于真实语义质量声明。
6. 将索引部署到 `var/knowledge_indexes/` 或配置的私有运行目录，并设置 `COACH_AGENT_KNOWLEDGE_INDEX_ID`。
7. 执行 Index validate 和 `python scripts/check_coach_rag_readiness.py --require-enabled`。
8. 使用完全虚构数据执行 `python scripts/smoke_coach_rag.py`。
9. 构建前端、重启 Gunicorn/Supervisor 服务并检查 health、OpenAPI 和 Coach 页面。
10. 小范围启用知识检索并观察安全状态、延迟和引用数量。

## 配置升级

需要按部署环境设置 Chat、Embedding、Knowledge Retrieval、Index ID、Top K、Index Runtime Directory 和超时。`.env.example` 只提供空值和安全默认值，不得直接写入真实 Key、密码或私有 Index ID。

默认配置下知识检索保持关闭。生产启用前必须同时满足：

- Corpus 校验通过；
- 真实索引与 Corpus、Provider、模型和维度一致；
- Index 不位于 Web Root，且被 Git 忽略；
- Readiness 返回 `READY`；
- 六场景核心 Smoke 通过。

## 回滚

1. 首先设置 `COACH_AGENT_KNOWLEDGE_RETRIEVAL_ENABLED=false`，保留不依赖 RAG 的 Coach 能力。
2. 如需恢复索引，切回上一有效 `COACH_AGENT_KNOWLEDGE_INDEX_ID` 并重新运行 Readiness。
3. Provider 故障时可以关闭 Coach Provider，使用确定性 Fallback。
4. 回滚后端和前端发布目录到 v0.11.0。
5. 本版本没有数据库迁移，无需数据库 downgrade。

## 安全与隐私

- 模型不能覆盖 TODAY 的 decision、计划状态、风险、数据质量、Warnings、Limitations 或 Evidence。
- 模型只能返回请求级 Reference ID，公共引用由服务端校验并还原。
- 不保存用户 Query、Prompt、Context、Tool Result、向量、Provider 原始回答或 `reasoning_content`。
- `var/knowledge_indexes/` 不进入 Git，也不得置于 Nginx Web Root。
- Coach 仍是只读工具，不自动修改训练计划，不构成医疗诊断。

## Alpha 范围与已知限制

- 当前为邀请制 Alpha，知识库规模有限。
- 暂无 Hybrid Retrieval、Reranker、长期记忆、写工具、自动计划修改、Streaming 或多 Agent。
- Provider 可能短暂失败，系统会安全降级。
- Quota 仍为进程内控制。
- 竞赛困难负例标签和人工盲评仍在完善，产品发布不表示竞赛总门禁已经完成。
