# GaitLogic Planner v0.16.0

## Retrieval architecture

v0.16.0 adds a pluggable retrieval layer for the versioned training-knowledge Corpus: Exact Dense retrieval, optional Qdrant Dense retrieval, deterministic BM25, fixed equal-weight Hybrid RRF, and an optional SiliconFlow reranker. Every strategy returns the existing public retrieval schema and preserves server-owned Canonical Knowledge References.

## Evaluation and default

Legacy Benchmark v1 remains a 60-case regression benchmark. The independent public fictional Holdout v2 contains 40 frozen cases and is the strategy-selection evidence. On Holdout v2, Dense Exact and Rerank each passed 33/40 cases; Dense Exact achieved Recall@4 0.936937 with lower operational complexity and no request-time reranker dependency. Therefore `dense` remains the v0.16.0 default. Rerank is real-provider evaluated but non-default.

## Safety

Metadata filters remain enforced before ranking. Reports retain forbidden-document analysis, do not hide failures, and do not contain raw queries, excerpts, vectors, Provider bodies, prompts, credentials, or private competition assets. Retrieval does not change TODAY deterministic decisions, training plans, or validator boundaries.

## Known limitations

The Corpus is intentionally small and Chinese-first. Qdrant is optional and requires a separately provisioned compatible index. Reranking depends on an external Provider and safely falls back to Hybrid RRF on Provider failure. No hybrid tuning, weighted RRF, query rewriting, hybrid expansion, or new retriever backend is introduced in this release.
