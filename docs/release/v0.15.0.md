# GaitLogic v0.15.0 Release Notes

## MCP

MCP SDK 2.0 is available over local stdio and authenticated Streamable HTTP. The public read-only Tools are `get_today_plan`, `get_recent_training`, `get_runner_state`, and `retrieve_training_knowledge`. Resources provide the public knowledge catalog, allowlisted documents, and capabilities; Prompts provide safe explanatory templates.

## Security and observability

Remote requests use a scoped MCP token, server-side identity injection and origin validation. No write Tool is exposed. Canonical references remove internal vector/index details, Resources reject arbitrary paths, and Trace/Metrics contain allowlisted operational metadata only.

## Evaluation

The offline public MCP regression suite contains 45 fixed checks. Unified regression preserves Coach 32/32, RAG 36/36, Weekly Adaptive 32/32, and the existing Retrieval baseline of 43/60 with 17 `RETRIEVAL_FAILURE` cases.

## Known limitations

MCP has no write Tools, remote OAuth flow, production external collector, Resources for user training data, or Provider calls. Retrieval's documented public baseline remains partial.
