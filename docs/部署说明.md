# 部署说明

本文档用于 GaitLogic Planner 内测环境部署参考。

## 1. 服务器环境要求

建议配置：

- Linux 服务器，Ubuntu 22.04 LTS 或同类发行版
- Python 3.11+
- Node.js 20 LTS+
- MySQL 8.0+
- Nginx 1.20+
- Git

暂时不强制使用 Docker。后续如加入 Docker 配置，可在本文件补充容器化部署流程。

## 2. MySQL 配置

创建数据库：

```sql
CREATE DATABASE IF NOT EXISTS gaitlogic_planner
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;
```

建议为应用创建独立账号，并只授权当前数据库：

```sql
CREATE USER 'gaitlogic'@'%' IDENTIFIED BY 'strong_password_here';
GRANT ALL PRIVILEGES ON gaitlogic_planner.* TO 'gaitlogic'@'%';
FLUSH PRIVILEGES;
```

项目 `.env` 示例：

```env
MYSQL_HOST=127.0.0.1
MYSQL_PORT=3306
MYSQL_USER=gaitlogic
MYSQL_PASSWORD=strong_password_here
MYSQL_DATABASE=gaitlogic_planner

JWT_SECRET_KEY=replace-with-a-long-random-secret
ACCESS_TOKEN_EXPIRE_DAYS=7
```

初始化表：

```bash
python scripts/init_db.py
```

## 3. 后端启动方式

安装依赖：

```bash
python -m pip install -e .
```

开发或内测临时启动：

```bash
uvicorn server.main:app --host 127.0.0.1 --port 8000
```

生产建议使用进程管理工具，例如 systemd、Supervisor 或 PM2 管理后端进程。示例命令：

```bash
uvicorn server.main:app --host 127.0.0.1 --port 8000 --workers 2
```

## 4. 前端 build 方式

进入前端目录：

```bash
cd web
npm install
npm run build
```

构建产物默认输出到项目根目录的 `web-dist/`。

如后端地址不是 `http://localhost:8000`，请配置：

```env
VITE_API_BASE_URL=https://your-domain.example.com
```

## 5. Nginx 反向代理示例

以下示例将前端静态文件和后端 API 放在同一个域名下：

```nginx
server {
    listen 80;
    server_name your-domain.example.com;

    root /opt/gaitlogic-planner/web-dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:8000/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

启用 HTTPS 时，建议使用 Certbot 或云厂商证书，并将 HTTP 自动跳转到 HTTPS。

## 6. 常见问题

### 登录时报 `JWT_SECRET_KEY is not configured`

检查 `.env` 是否存在，并确认包含：

```env
JWT_SECRET_KEY=replace-with-a-long-random-secret
```

修改 `.env` 后需要重启后端。

### 接口返回数据库字段不存在

通常是数据库表结构没有更新。执行：

```bash
python scripts/init_db.py
```

如果是历史数据库缺列，需要补充对应升级脚本或手动执行 DDL。

### 前端请求后端跨域失败

开发环境默认允许：

```text
http://localhost:5173
```

如果部署域名不同，需要在后端 CORS 配置中加入对应域名。

### 前端刷新页面 404

Nginx 需要配置：

```nginx
try_files $uri $uri/ /index.html;
```

### MySQL 连接失败

检查：

- MySQL 服务是否启动
- `.env` 中账号密码是否正确
- 服务器防火墙是否允许连接
- 数据库字符集是否为 `utf8mb4`
